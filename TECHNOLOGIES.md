# Технологии Delivery Simulator

## Основной стек

| Область | Технология |
|---|---|
| Движок | Unity 2022.3.6f1 LTS |
| Язык | C# |
| Рендеринг | Universal Render Pipeline 14.0.8 |
| Ввод | Unity Input System 1.6.3 |
| Камеры | Cinemachine 2.9.7 |
| Навигация | Unity AI Navigation 1.1.4 |
| Анимация | Animation Rigging 1.2.1, Timeline 1.7.5 |
| UI | uGUI 1.0.0 и TextMeshPro 3.0.6 |

## Мультиплеер

- Photon PUN/Realtime использовался для создания и подключения к комнатам.
- Пользовательские компоненты управляют сетевой сессией, подключением и спавном игроков.
- Игровая логика отделена от сетевого слоя через специализированные Photon-компоненты.

## Игровые системы

- Менеджер миссий и жизненный цикл доставки.
- Данные заказов, продуктов, типов магазинов и активных заданий.
- Интерьеры магазинов, выбор товаров и подготовка ресторанов.
- Завершение доставки в точке назначения и переход к следующей миссии.
- Сохранение прогресса и пользовательских настроек.
- Главное меню, загрузочные экраны и общий UI-менеджер.
- Визуальные представления игрока и ragdoll-компоненты.

## Unity-пакеты

- Burst 1.8.7 и Collections 1.2.4.
- Post Processing 3.2.2.
- ProGrids 3.0.3-preview.6 для построения уровней.
- Visual Scripting 1.8.0.
- Unity Test Framework 1.1.33.
- Rider, Visual Studio и VS Code интеграции.

## Портфолио-версия

Репозиторий предназначен для демонстрации оригинального кода миссий, доставки, UI, сохранений и сетевого потока. Коммерческие города, транспорт, интерьеры, UI-паки, Photon SDK и другие сторонние ассеты исключены, поэтому для полного запуска потребуются исходные лицензированные зависимости.
