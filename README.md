# Delivery Simulator

Portfolio source snapshot of a Unity delivery-game prototype with missions, shops, vehicle-oriented gameplay, persistence, and Photon-based multiplayer flow.

For a detailed technology stack and architectural overview, see [TECHNOLOGIES.md](TECHNOLOGIES.md).

## Highlights

- Mission lifecycle, order and product data, delivery completion, and destination handling.
- Shop interiors, product selection, restaurant setup, bike shop flow, and mission assignment.
- Save management, settings, loading screens, menus, and UI coordination.
- Photon room creation, joining, player spawning, and multiplayer session handling.

## Source layout

- `Assets/Scripts` — original gameplay, mission, UI, persistence, and multiplayer code.
- `Assets/Scenes` — lightweight scene data retained for architectural context.
- `Assets/Prefabs`, `Assets/Resources`, and `Assets/Settings` — supporting authored configuration.
- `Packages` and `ProjectSettings` — Unity package and project configuration.

## Portfolio note

Commercial city, vehicle, interior, UI, and environment packages are intentionally excluded. This repository is a code portfolio and does not reproduce the full game without the licensed assets.
